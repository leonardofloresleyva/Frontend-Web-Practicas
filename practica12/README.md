## **Preguntas de la práctica**

### **Paso 1.1: ¿En qué se convirtió cada etiqueta del JSX?**
#### En una función que regresa un componente de React

### **Paso 1.2: Si React es «sólo una biblioteca»,¿Quién traduce el JSX?**
#### La herramienta SWC.

### **Paso 2: ¿Qué hace createRoot y qué hace render?**
#### createRoot obtiene el objeto DOM a partir del cual se pintarán otros componentes de React (típicamente la raíz) y render pinta los componentes como tal.

### **Paso 3: ¿Por qué el nombre de un componente empieza con mayúscula?**
#### Porque, si empezara con minúscula, React lo consideraría una etiqueta HTML.
